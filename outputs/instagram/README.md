# Instagram Outputs

Use this folder for Instagram-specific content.

Subfolders:

- `reels/`: Reel hooks, short scripts, voiceovers, and shot ideas.
- `carousels/`: Carousel drafts, slide-by-slide copy, and post structures.
- `captions/`: Caption drafts and finished captions.
- `stories/`: Story prompts, polls, question boxes, and story sequences.
- `content-calendars/`: Weekly or monthly Instagram plans.

Before creating Instagram content, use:

- `strategy/current-instagram-strategy.md`
- `strategy/content-performance-rules.md`
- `strategy/content-pillars.md`
- `strategy/tone-of-voice.md`
- relevant prompt templates from `prompts/`

Instagram priority: emotional recognition first, education second.
