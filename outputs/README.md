# Outputs

Use this folder for drafted and finished Andrum materials.

Think of `outputs/` as the project shelf: every folder is a different type of final or in-progress work, but all of them can use the same shared knowledge from `brand/`, `product/`, `strategy/`, `research/`, and `prompts/`.

## Folder Map

- `instagram/`: Reels, carousels, captions, stories, and Instagram content calendars.
- `marketing/`: Campaign ideas, launch plans, offers, funnels, and general marketing materials.
- `landing-pages/`: Landing page copy, page structures, section drafts, and website messaging.
- `email/`: Email sequences, newsletters, launch emails, and nurture flows.
- `ads/`: Paid ad concepts, hooks, scripts, and variants.
- `scripts/`: Video scripts, voiceover scripts, podcast-style scripts, and talking points.
- `product-copy/`: Product descriptions, practice copy, app/store copy, onboarding text, and UX microcopy.
- `strategy-notes/`: Working strategy notes created during projects.

## Naming

- `YYYY-MM-DD-topic.md`
- `reel-topic.md`
- `carousel-topic.md`
- `landing-page-sos-practices.md`
- `email-sequence-anxious-attachment.md`
- `ad-hooks-sos-practices.md`

## How To Use

When asking Codex to create something, name:

1. The task type.
2. The source folders to use.
3. The output folder.

Example:

> Use `brand/`, `product/`, `strategy/`, and `research/audience/` to write landing page copy for SOS Practices. Save it in `outputs/landing-pages/`.

Example:

> Use the Andrum strategy files to create 10 Instagram Reel ideas. Save them in `outputs/instagram/reels/`.
