# Ads

Use this folder for paid ad materials.

Examples:

- ad hooks
- short video ad scripts
- static ad copy
- headline variants
- pain-point angles
- testing matrices

Useful source folders:

- `brand/`
- `product/`
- `strategy/content-performance-rules.md`
- `research/audience/`

Ads should lead with a specific emotional moment, not a broad promise.
