# Product Copy

Use this folder for product-related copy.

Examples:

- product descriptions
- practice descriptions
- onboarding copy
- app or website microcopy
- pricing page copy
- product update notes

Useful source folders:

- `product/`
- `brand/`
- `strategy/target-audience.md`
- `research/customer-journey/`

Product copy should explain what the user feels, what they can do next, and why the practice is useful without sounding clinical.
