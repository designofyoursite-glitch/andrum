# Email

Use this folder for email content.

Examples:

- newsletters
- nurture sequences
- launch sequences
- onboarding emails
- re-engagement emails

Useful source folders:

- `brand/`
- `product/`
- `strategy/tone-of-voice.md`
- `research/audience/`

Emails can go slightly deeper than Instagram, but should still feel personal, simple, and emotionally recognizable.
