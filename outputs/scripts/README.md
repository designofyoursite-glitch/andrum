# Scripts

Use this folder for longer-form scripts and spoken content.

Examples:

- video scripts
- voiceover scripts
- podcast-style notes
- interview questions
- talking points
- workshop or session outlines

Useful source folders:

- `brand/`
- `product/`
- `strategy/tone-of-voice.md`
- `research/interview-transcripts/`

Scripts should sound spoken, not written. Keep sentences natural and easy to say out loud.
