# Marketing

Use this folder for broader Andrum marketing work that is not only Instagram.

Examples:

- launch plans
- campaign ideas
- offer angles
- funnel notes
- customer journey messaging
- partnership ideas
- positioning drafts

Useful source folders:

- `brand/`
- `product/`
- `strategy/`
- `research/audience/`
- `research/customer-journey/`

Marketing should still sound like Andrum: clear, emotionally specific, and human. Avoid generic wellness or online-business language.
