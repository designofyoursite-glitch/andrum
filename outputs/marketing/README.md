# Marketing

Use this folder for broader Andrum marketing work that is not only Instagram.

Examples:

- launch plans
- campaign ideas
- offer angles
- funnel notes
- customer journey messaging
- partnership ideas
- positioning drafts

Useful source folders:

- `brand/`
- `product/`
- `strategy/`
- `research/audience/`
- `research/customer-journey/`

Marketing should still sound like Andrum: clear, emotionally specific, and human. Avoid generic wellness or online-business language.

## Marketing Data Storage System

Use a hybrid storage system for performance data and funnel analysis:

1. Keep one detailed markdown file per test in `outputs/marketing/`.
2. Create a master dashboard in `outputs/marketing/funnel-dashboard.md` once there are at least 3 tests to compare.
3. Later add `research/analytics/meta-ads-tests.csv` when comparison across tests becomes too hard to manage in markdown.
4. Keep ad scripts and new creative concepts in `outputs/ads/`, but link to them from the relevant test log.
5. Keep landing page copy changes in `outputs/landing-pages/` only if they are draft copy. Keep performance conclusions in `outputs/marketing/`.

For now, `outputs/marketing/2026-06-15-meta-ads-free-practice-launch-01.md` is the canonical record for Launch 01.

Every test log should include the objective, offer, traffic source, campaign/ad names, creative copy, landing page state, spend, clicks, landing page views, leads, purchases when available, facts, hypotheses, data gaps, bottleneck, next action, and decision made.
