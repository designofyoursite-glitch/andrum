# Landing Pages

Use this folder for website and landing page copy.

Examples:

- full landing page drafts
- page section outlines
- hero copy
- product page copy
- FAQ sections
- testimonials or proof sections

Useful source folders:

- `brand/`
- `product/`
- `strategy/target-audience.md`
- `strategy/tone-of-voice.md`
- `research/audience/`

Landing page copy should be emotionally direct, specific, and conversion-aware without sounding pushy.
