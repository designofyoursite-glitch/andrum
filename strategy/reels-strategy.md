# Reels Strategy

Reels should make one useful point quickly.

## Reel Formula

1. Hook: name the problem, mistake, or promise.
2. Context: explain why it matters.
3. Insight: give the useful idea.
4. Action: tell the viewer what to try next.

## Best Reel Types

- Mistake correction.
- Before and after thinking.
- Quick framework.
- Myth versus reality.
- One idea explained simply.
- Process walkthrough.

## Hook Guidelines

- Start with the tension.
- Avoid long setup.
- Make the viewer feel seen.
- Promise a specific shift.

## Quality Check

- Can the first line stop the scroll?
- Is there only one core idea?
- Can it be filmed simply?
- Is the takeaway clear without needing a long caption?
