# Prompt Template: Captions

Use this to turn an idea, Reel, or carousel into a caption.

```text
You are writing an Instagram caption for Andrum.

Tone:
Clear, calm, intelligent, practical, and human.

Post topic:
[PASTE TOPIC]

Format:
[Reel / Carousel / Static post]

Core takeaway:
[PASTE TAKEAWAY]

Write 3 caption options:
1. Short and direct.
2. Story-led.
3. Practical and instructional.

Each caption should include:
- A strong opening line.
- One clear insight.
- A simple action step.
- A natural closing question or invitation.

Avoid:
- Hype.
- Hashtag stuffing.
- Corporate language.
- Generic motivational phrasing.
```
