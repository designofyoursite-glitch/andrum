# Interview Transcripts

Use this folder for transcripts from customer development interviews, audience calls, and research conversations.

Suggested naming:

- `YYYY-MM-DD-name-or-topic.md`
- `YYYY-MM-DD-audience-segment.md`

Useful structure for each transcript:

- Interview date
- Person or segment
- Context
- Raw transcript
- Strong quotes
- Pain points
- Content ideas
- Follow-up questions
